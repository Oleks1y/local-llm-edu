# Локальні LLM — презентація

Публічна сторінка з україномовною презентацією: [відкрити GitHub Pages](https://oleks1y.github.io/local-llm-edu/).

Цей репозиторій містить лише готовий автономний `index.html`. Редаговані матеріали й документація зберігаються в окремому приватному репозиторії. Щоб оновити сайт, скопіюйте зібраний `presentation.html` із приватного проєкту в `index.html` і опублікуйте новий коміт.
